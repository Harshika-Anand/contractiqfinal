# Drivers Folder

Place your WebDriver executables here:

## Required Downloads

### Chrome (Recommended)
- Download ChromeDriver from: https://chromedriver.chromium.org/downloads
- File to place here: `chromedriver.exe`

### Firefox (Alternative)
- Download GeckoDriver from: https://github.com/mozilla/geckodriver/releases
- File to place here: `geckodriver.exe`

### Edge (Alternative)
- Download Edge WebDriver from: https://developer.microsoft.com/en-us/microsoft-edge/tools/webdriver/
- File to place here: `msedgedriver.exe`

## How to Find Your Browser Version

### Chrome
1. Open Chrome
2. Click three dots menu → Help → About Google Chrome
3. Note the version number (e.g., 120.0.6099.130)

### Firefox
1. Open Firefox
2. Click menu → Help → About Firefox
3. Note the version number

### Edge
1. Open Edge
2. Click three dots → Help and feedback → About Microsoft Edge
3. Note the version number

## Important
- Download the driver that matches your browser version EXACTLY
- Mismatched versions will cause errors
